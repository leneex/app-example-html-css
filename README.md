# Static (HTML / CSS / JS)

Пример статического приложения (HTML / CSS / JS), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — готовые файлы |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Путь проверки состояния | `/` |

Порт и команды указывать не нужно: сборки нет, файлы из директории проекта отдаются как есть на
порту 80.

## <a name="dev"></a>Локальный запуск проекта

**Проект не имеет возможности сборки.**

Просмотр содержимого осуществляется через открытие index.html любым браузером
