# Static (HTML / CSS / JS)

Example static site (HTML / CSS / JS). Plain HTML, CSS and JavaScript files are served as is, with no build step.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — prebuilt files |
| Single-page application (SPA) | off |
| Project directory | `/` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

**This project does not have a build step.**

Open index.html in any browser to view the content.
